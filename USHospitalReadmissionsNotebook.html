Hospital Readmissions Analysis¶

Project Overview¶

This project analyzes publicly available hospital-level performance data from the Centers for Medicare & Medicaid Services (CMS).

Business Objective¶

  • Classify hospitals into three groups based on average readmission ratios.
  • Identify hospitals with higher-than-expected readmission ratios.
  • Evaluate hospital readmission performance against the expected ratio of 1.00.

Tools¶

  • Python
  • pandas
  • Matplotlib
  • Seaborn

# Clean the readmission ratio
data["Excess Readmission Ratio"] = pd.to_numeric(
    data["Excess Readmission Ratio"], errors="coerce"
)

data = data.dropna(
    subset=["Facility ID", "Facility Name", "State"]
)

ratio_col = "Excess Readmission Ratio"

# Report missing ratios before excluding them
missing_count = data[ratio_col].isna().sum()
missing_percent = data[ratio_col].isna().mean() * 100

print("Missing readmission ratios:", missing_count)
print(f"Percentage missing: {missing_percent:.2f}%")

# Keep valid positive ratios for the analysis
data = data[
    data[ratio_col].notna() &
    (data[ratio_col] > 0)
].copy()

print("Records remaining after cleaning:", len(data))

data = data[data["Excess Readmission Ratio"] > 0].copy()

Aggregate hospitals and perform K-Means clustering¶

# Calculate the average ratio for each hospital
hospital_data = data.groupby(
    ["Facility ID", "Facility Name", "State"],
    as_index=False
).agg(
    Average_Ratio=("Excess Readmission Ratio", "mean"),
    Number_of_Measures=("Measure Name", "nunique")
)

# Prepare the data for clustering
X = hospital_data[["Average_Ratio"]]

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Create three hospital clusters
kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
hospital_data["Cluster"] = kmeans.fit_predict(X_scaled)

# Name clusters from lowest to highest ratio
cluster_order = hospital_data.groupby("Cluster")[
    "Average_Ratio"
].mean().sort_values().index.tolist()

cluster_names = {
    cluster_order[0]: "Lower Ratio",
    cluster_order[1]: "Middle Ratio",
    cluster_order[2]: "Higher Ratio"
}

hospital_data["Cluster Name"] = hospital_data["Cluster"].map(
    cluster_names
)

# Display the cluster summary
cluster_summary = hospital_data.groupby("Cluster Name").agg(
    Number_of_Hospitals=("Facility ID", "nunique"),
    Average_Ratio=("Average_Ratio", "mean"),
    Median_Ratio=("Average_Ratio", "median")
).reindex(
    ["Lower Ratio", "Middle Ratio", "Higher Ratio"]
).round(3)

print("\nHOSPITAL CLUSTER SUMMARY")
print(cluster_summary)

Results Summary¶

  • Data Cleaning: 11,720 records remained after excluding 6,610 records with missing readmission ratios.
  • Lower Ratio Cluster: 40 hospitals had an average ratio of 0.754, indicating fewer readmissions than expected on average.
  • Middle Ratio Cluster: 1,623 hospitals had an average ratio of 0.973, close to the expected ratio of 1.00.
  • Higher Ratio Cluster: 1,170 hospitals had an average ratio of 1.045, indicating more readmissions than expected on average.
  • Highest Readmission Ratio: Surgical Institute of Reading in Pennsylvania had the highest average ratio at 1.3097, approximately 31% above the expected level.
