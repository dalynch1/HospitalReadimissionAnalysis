# HospitalReadimissionAnalysis
Analyzing hospital readmission data using Python and K-Means clustering to group hospitals by excess readmission ratios, visualize performance patterns, and identify potential opportunities for healthcare quality improvement.

## Project Overview
This project uses Python and K-Means clustering to group hospitals based on their average Excess Readmission Ratios. The goal is to identify readmission patterns and potential opportunities for healthcare quality improvement.

## Tools & Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook
## Business Objectives
- Classify hospitals into three readmission-ratio groups.
- Identify hospitals with higher-than-expected readmission ratios.
- Visualize hospital readmission performance.
- Support data-driven healthcare quality improvement.
## Methodology
- Clean and preprocess hospital readmission data.
- Calculate the average readmission ratio for each hospital.
- Standardize the data using StandardScaler.
- Apply K-Means clustering with three clusters.
- Visualize results and export hospital cluster assignments.
